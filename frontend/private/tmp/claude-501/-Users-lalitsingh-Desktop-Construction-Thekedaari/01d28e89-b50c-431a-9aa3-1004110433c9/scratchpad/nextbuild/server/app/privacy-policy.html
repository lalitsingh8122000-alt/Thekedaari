01

Information We Collect

Thekedaari app use karte waqt hum kuch zaroori information collect karte hain taaki app sahi se kaam kare.

1.1 Account Information

Jab aap Thekedaari pe register karte ho, hum collect karte hain:

  • Aapka naam (jaise "Lalit Singh")
  • Phone number (login aur account identification ke liye)
  • Account creation date
  • Profile photo (optional — aap upload na karo toh bhi chalta hai)

1.2 App Usage Data (Jo Aap Enter Karte Ho)

  • Worker ke naam, phone numbers, aur daily rates
  • Attendance records (Present/Absent/Half Day)
  • Payment aur salary records
  • Project names, budgets, aur financial transactions
  • Worker ledger entries (salary, bonus, advance payments)

1.3 Technical Data (Automatically Collected)

  • Device type aur operating system (Android/iOS)
  • Browser ya app version
  • App usage patterns — anonymously
  • Error logs (app crash hone pe fix karne ke liye)

Note: Hum aapki location, contacts, ya camera access kabhi bhi background mein nahi lete. Jo permission maange jaate hain, woh sirf specific features ke liye hote hain aur aapki consent se.

2.1 App Functionality

  • Aapka account create karna aur login karna

  • Project finance aur ledger calculate karna

Data Storage & Security

Aapka data secure rakhna hamari pehli zimmedari hai.

3.1 Where Is Data Stored

Thekedaari ka data India mein secure cloud servers par store hota hai. Hum industry-standard encryption use karte hain data store karte waqt (at rest) aur transfer karte waqt (in transit).

3.2 Security Measures

  • HTTPS encryption — saara data encrypted channel se travel karta hai
  • Password hashing — aapka password plain text mein kabhi store nahi hota
  • Regular security audits aur vulnerability checks
  • Access controls — sirf authorized team members ko production data access
  • Automatic backups — data loss se protection

3.3 Data Retention

Jab tak aapka account active hai, aapka data hum store karte hain. Account delete karne ke baad:

  • Personal data 30 din ke andar permanently delete ho jaata hai
  • Anonymized usage statistics retain ki ja sakti hain
  • Legal requirements ki wajah se kuch records 90 days tak ho sakti hain

Important: Koi bhi security system 100% guarantee nahi de sakta. Agar aapko koi security issue dikhe, please turant LALITSINGH8122000@gmail.com par report karein.

Information Sharing & Third Parties

Simple rule: Hum aapka data kabhi bhi sell nahi karte. Period.

Thekedaari kisi bhi third party ke saath aapka personal data share nahi karta, sirf in cases ko chhodkar:

4.1 Service Providers

  • Cloud Hosting: Server infrastructure ke liye
  • Authentication Services: Secure login ke liye (phone OTP verification)
  • Error Monitoring: App crashes track karne ke liye (anonymized)

4.2 Legal Requirements

Agar Indian law, court order, ya government authority require kare, tab hum legally bound hain data share karne ke liye.

4.3 Business Transfer

Agar Thekedaari kabhi merge ya acquire ho, aapka data transfer ho sakta hai. Lekin hum aapko pehle notify karenge aur aapko data delete karne ka option milega.

Cookies & Local Storage

Thekedaari ek PWA (Progressive Web App) hai. Hum use karte hain:

6.1 Essential Cookies / Local Storage

  • Session tokens: Aapko logged in rakhne ke liye
  • App preferences: Language setting (Hindi/English), dark mode
  • Offline data cache: App offline kaam kar sake isliye

6.2 Analytics (Anonymous)

  • Hum anonymized usage data collect karte hain app improve karne ke liye
  • Yeh data aapko personally identify nahi karta
  • Koi third-party advertising cookies use nahi karte hain

Browser settings: Aap browser mein cookies clear kar sakte ho, lekin isse app ki functionality affect ho sakti hai (logout ho sakte ho).
